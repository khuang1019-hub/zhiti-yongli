State Farm：受治理的 Copilot Studio Agent 规模化

保险 HR、核保、内容与翻译、IT 平台团队 精选
行业
保险
角色
HR、核保、内容与翻译、IT 平台团队
工具栈
Microsoft Copilot Studio、Power Platform、SharePoint、Entra ID

摘要

41 个通过风险评估的生产构建；Power Platform 内 3000+ Agent 身份。Ask HR 政策 Agent 减轻人工答疑；核保准则检索 Agent 上线 30 天内成为第二常用；营销翻译周转从约 12 个月压到约 24 小时。强调治理与人工问责先行。

步骤摘要

  1. 负责任 AI 工坊 + 阶梯式建设（个人→团队→部门→企业）
  2. 风险与合规审批路径清晰后再进生产
  3. 知识类 Agent（HR/核保手册）优先
  4. 目录化复用连接器与入职/离职方案
  5. 规划向跨系统编排与行动型 Agent 演进

风险与注意

知识库过时导致误导；核保等关键决策必须人责；规模化后 Agent 身份与权限治理成本上升。
