Asurion：发票异常处理 Agent，免人工处理率从不足 20% 升到 70%+

保险 / 设备保障服务 财务应付（AP）
行业
保险 / 设备保障服务
角色
财务应付（AP）
工具栈
Microsoft Copilot Studio、Power Automate、Dynamics 365 Finance 发票采集

摘要

Asurion 每年约 3 万张直接采购订单发票、约九成带至少一个异常，免人工处理率一度跌破 20%。团队把 Copilot Studio Agent 嵌进 Power Automate 流程：发票进入错误状态时由 Agent 按既定规则修正料号、订单号等再回流入账。约一周做出验证，上线首周北美/南美供应商提升到 55% 以上，后续达到 70% 以上，目标 85%。

步骤摘要

  1. 发票采集识别出错误状态的数据
  2. Power Automate 抽取相关字段路由给 Agent
  3. Agent 按确定性指令修正外部料号、订单号等
  4. 后续流程重处理，完整发票进入财务系统
  5. 按供应商与区域逐步扩展，规划分录与对账场景

风险与注意

来源为微软客户案例，厂商渠道；场景是确定性规则修正，需最小权限、尽量只读和人工复核节点；MCP 能力仍在 QA。
