来伊份×火山引擎：200+智能体进门店巡检与补货

零售连锁 门店运营、督导、供应链、审批流负责人 精选
行业
零售连锁
角色
门店运营、督导、供应链、审批流负责人
工具栈
火山引擎 HiAgent、豆包大模型、现有数字化中台

摘要

创建 500+ 智能体，其中 200+ 落地：AI 巡检覆盖近 3000 家门店，AI 补货覆盖 1500+ 门店；智能审批耗时降低约 70%；飞单识别准确率公开披露约 95%。采用「1+N+X」矩阵与数据/能力分级治理。

步骤摘要

  1. 核心系统上云并部署统一 AI 中台（HiAgent）
  2. 业务侧成立智能提升组，按开店/运店/商品等域建 Agent
  3. 巡检 Agent 多模态识别陈列/物料/空置与异常交易
  4. 补货 Agent 按门店特征生成差异化补货清单
  5. 审批 Agent 智能提醒与自动审批，关键节点保留人工

风险与注意

加盟门店执行一致性；误报飞单影响一线信任；敏感数据五级分级与 Agent 五级能力边界需持续治理。
