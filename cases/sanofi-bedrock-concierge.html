赛诺菲 Concierge：全球员工 Agent 入口（AWS Bedrock）

医药 / 生物制药 研发、制造供应、职能横向团队
行业
医药 / 生物制药
角色
研发、制造供应、职能横向团队
工具栈
Amazon Bedrock、自建 Concierge、Agent Hub 编排层

摘要

2026Q1：周活约 5 万、月活约 7.2 万、累计约 1100 万次对话、正面反馈约 90%；调查称约 90.5% 员工节省常规任务时间。Concierge 作为发现与编排入口，连接检索、回写与流程自动化专业 Agent。

步骤摘要

  1. 自建、可换模型、多区域部署降延迟
  2. 从生产力助手升级为数字网关
  3. 建设 Agent Hub 连接专业 Agent
  4. 社区超级用户分享工作流，持续扩能力（含 AgentCore）

风险与注意

制药数据敏感与合规；幻觉导致错误决策；遗留应用千万级导航替代需权限与审计严密。
