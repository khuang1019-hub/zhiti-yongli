富士通：约 10 万席 Copilot，服务台初响自动化约 75%

IT 服务 / 综合科技 服务台、全体知识工作者
行业
IT 服务 / 综合科技
角色
服务台、全体知识工作者
工具栈
Microsoft 365 Copilot、企业内部 Fujitra 转型网络

摘要

从 7500 席试点扩至约 10 万席；有权限员工中使用率曾报超 90%。服务台年询约 30 万，AI Agent 承接约 75% 的初响与分诊，员工更多投入知识质量与准确率改进。

步骤摘要

  1. 小规模跨部门试点验证价值
  2. 分阶段扩容席位与接入系统
  3. 服务台初响/分诊 Agent 上线
  4. 以 Copilot 为入口连接专业 Agent 与业务系统

风险与注意

客户现场/高安全环境无法覆盖；依赖知识内容质量；自动化分诊错误会放大工单路由成本。
