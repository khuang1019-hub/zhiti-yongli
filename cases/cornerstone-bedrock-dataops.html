Cornerstone：多 Agent 数据库故障诊断，从 45 分钟缩到 10 分钟

企业软件 / SaaS DataOps、SRE
行业
企业软件 / SaaS
角色
DataOps、SRE
工具栈
Amazon Bedrock、Strands Agents 多 Agent 编排

摘要

Cornerstone OnDemand 的 DataOps 团队过去每次数据库事故要花最多 45 分钟手工查系统视图、对日志再跨团队交接。其 Orion AI 多 Agent 系统按领域分工协同，诊断时间降到 10 分钟（约 78%），手工生命周期步骤减少约 70%，冗余告警中位数降 65%。三人团队用六个月交付。

步骤摘要

  1. 告警进入后路由到对应领域的专职 Agent
  2. Agent 查询系统视图与日志、汇总诊断
  3. 混合路由：常见问题走固定路径，复杂问题交多 Agent 协同
  4. 会话级记忆加实时指标直取，避免用过期数据
  5. 结果同步给 SRE，过滤重复告警

风险与注意

来源为 AWS 机器学习博客（与客户联合署名），厂商渠道；涉及生产数据库，需限定只读与操作审批；指标为企业自报。
