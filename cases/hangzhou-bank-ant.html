杭州银行×蚂蚁数科：多 Agent 营销策略生成

银行零售/对公经营 客户经营、产品与策略团队
行业
银行零售/对公经营
角色
客户经营、产品与策略团队
工具栈
蚂蚁数科多 Agent（客户洞察/产品分析/营销策略）

摘要

IDC 案例观察：基于多个 Agent 处理客户洞察、产品分析与营销策略，项目测算策略生成时间从天级缩短到分钟级。可与杭州银行公开的智能展业体系表述交叉阅读。

步骤摘要

  1. 客户洞察 Agent 汇总画像与信号
  2. 产品分析 Agent 匹配可售产品
  3. 策略 Agent 生成营销方案
  4. 人工合规校验后触达与复盘

风险与注意

金融营销合规与适当性；分钟级产出需质检；IDC 为摘要口径。
